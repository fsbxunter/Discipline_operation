# Операция "Дисциплина" v2.1

Геймифицированный тренажёр дисциплины с кастомными заданиями.

---

## Как добавить задание

1. Запусти игру  
2. Нажми **TAB**  
3. Введи:  
   - **ТИП** (напр. `ТАКТИКА`)  
   - **НАЗВАНИЕ** (напр. `Медитация 15 минут`)  
   - **МИНУТ** (напр. `15`)  
4. Нажми **ДОБАВИТЬ ЗАДАНИЕ**  
5. Снова **TAB** — вернуться к игре

Задания сохраняются навсегда.

---

## Управление

- **TAB** — показать/скрыть форму добавления  
- Клик по кнопкам — действия
